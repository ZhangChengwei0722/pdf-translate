# Code of Conduct

This project follows the Contributor Covenant spirit of a welcoming, respectful, and harassment-free community.

Expected behavior includes:

- being respectful and constructive;
- discussing code, documentation, and evidence rather than people;
- accepting good-faith technical disagreement;
- protecting private documents, credentials, and security reports.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, deliberate exposure of private data, and disruptive personal attacks.

Maintainers may edit, close, or remove contributions that violate these expectations. Report conduct concerns privately through the security reporting channel described in `SECURITY.md` or through a GitHub contact route available to the repository owner.

This document is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
