# Security Policy

## Supported versions

Only the latest version on the default branch is actively maintained. Older snapshots may not receive security fixes.

## Reporting a vulnerability

Do not include API keys, private PDFs, provider responses, or exploitable details in a public issue.

Use GitHub's private vulnerability reporting or Security Advisory flow for this repository when it is available. If that flow is not enabled, open a minimal public issue that contains only the label `security` and the words "private contact needed"; do not disclose the vulnerability until a private channel has been established.

Please include a short impact summary, affected file or command, reproduction conditions without secrets, and any proposed mitigation. Reports are triaged as time permits. This project is a local skill and does not operate a hosted translation service; provider credentials and user documents remain outside this repository.
